# Research Prompt Pack

Quick-start prompts for US and A-share research.

## A-Share Deep Scan

```text
用 serenity-skill 深度调研现在 A 股 [行业/主题]。
请联网查公告、财报、问询函、互动易、招投标、环评/能评、专利、客户认证和财务质量，
先排产业链层级，再找 5 个最值得优先研究的标的，
并说明卡住的环节、产业链位置、证据、排序理由和主要风险。
```

## US Deep Scan

```text
Use serenity-skill to deeply research US-listed [theme] companies.
Map the value chain, check SEC filings, transcripts, customer concentration,
financing risk, margin evidence (GAAP, not non-GAAP), and the parts of the
value chain investors may be underpricing. Build a 20+ candidate universe,
rank the top 5-7 priorities, and explain evidence, risks, and next checks.
```

## Single-Company Challenge (US)

```text
Use serenity-skill to challenge [TICKER].
Where does it sit in the value chain? Does it control a scarce layer?
What evidence supports the idea, what evidence is missing, and what would weaken the judgment?
If covered in ticker-theses.md, pull Serenity's stance, conviction tier, and evolution.
```

## Single-Company Challenge (A-Share)

```text
用 serenity-skill 挑战 [公司/股票代码]。
它到底卡在哪一层？证据够不够？市场可能高估了什么？
什么情况说明这个判断应该降级？
```

## Candidate Comparison

```text
Use serenity-skill to compare [A], [B], and [C].
Rank by supply-chain position, evidence quality, customer urgency,
valuation pressure, main risk, and next verification step.
For US names, cross-reference Serenity's theses if covered.
```

## Portfolio Review (US)

```text
Use serenity-skill to review my watchlist: [TICKER1], [TICKER2], [TICKER3].
For each, pull Serenity's stance from ticker-theses.md. Note conviction tier and evolution.
Bucket into Agreements, Conflicts, and Gaps. Flag article-backed signals. Keep advisory.
```

## Sector View

```text
Use serenity-skill to form a forward view on the [sector] sector.
Identify thematic threads, pull key theses, note leading indicators,
state confidence levels with dated evidence, and what would invalidate the outlook.
```

## Ticker Through Serenity's Lens

```text
Use serenity-skill to evaluate [TICKER] through Serenity's lens.
Pull stance from ticker-theses.md, note conviction tier and evolution,
run the 15-point checklist from methodology-lens.md, confirm current price/fundamentals.
```

## Research Partner Mode

```text
用 serenity-skill 陪我讨论 [主题/公司]。
不要直接写报告，每轮先给判断，再问我一个最关键的问题，
带我从故事拆到产业链卡点和证据。
```

## Scorecard

```text
Use serenity-skill's local scorecard to score [company].
Explain every rating in plain language and mark evidence as strong/medium/weak/needs checking.
```
