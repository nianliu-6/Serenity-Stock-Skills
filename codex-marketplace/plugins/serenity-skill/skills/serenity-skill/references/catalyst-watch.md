# Catalyst Watch

Use this file when the user asks for a watchlist, monitor, follow-up tracker, timeline, ongoing lane tracker, or "what should I watch next?"

## Goal

Move from one-off analysis to timeline-based monitoring while keeping the output as research support, not trading instructions.

## Catalyst Types

- earnings date or guidance update
- qualification milestone
- capacity-expansion announcement
- first volume shipment
- customer onboarding
- supplier-list change
- product launch or design win
- policy, subsidy, export-control, or funding event
- financing event, ATM, convert, placement, pledge, or refinancing
- monthly revenue, utilization, backlog, lead-time, inventory, or margin data

## What To Track

For each lane or candidate, track:

1. the next three catalyst events;
2. what confirmation would strengthen the thesis;
3. what negative surprise would weaken it;
4. which companies or layers should react first;
5. which source path should be checked next.

## Evidence Discipline

Refresh current facts before creating or updating a catalyst watch. Use current filings, exchange documents, company IR, earnings transcripts, official announcements, regulator/project records, and market data when available.

Label every catalyst:

- `Confirmed`: event/date/source is directly documented.
- `Inferred`: event is likely from known reporting cadence or supply-chain timing.
- `Weak`: event depends on secondary reporting.
- `Needs verification`: event came from social posts, dated references, or incomplete source paths.

## Output Pattern

```text
Catalyst Watch

Next events:
- Q2 earnings: watch for lead-time and customer qualification language [Confirmed]
- Capacity update: watch for allocation/booked-out wording [Inferred]
- Customer launch: watch for supplier mentions [Needs verification]

Bullish confirmation:
- Management confirms qualification completed and volume ramp starts.

Bearish confirmation:
- Customer signals dual-sourcing, delay, margin pressure, or no bottleneck.

Most sensitive names/layers:
- ...

Next source checks:
- SEC 10-Q / exchange announcement / IR deck / transcript / project filing.
```
